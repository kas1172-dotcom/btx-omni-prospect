# Public market observations

Owner: `modules/markets`; storage shares the application PostgreSQL database. Apply migration `0026_market_series`. `GET /api/markets` and `/api/markets/{series_id}` require a normal session and never trigger public fetching. Decimal observations are independent of internal revenue, account scores, Monitor events and capacity assertions.

The reviewed registry `BTX_MARKET_SERIES_1` currently enables four Federal Reserve Board G.17 seasonally adjusted industrial-production indices, 2017=100, using NAICS2022. Exact codes: G3364, G3344, N3391, G3353. Broad aerospace, electronic-component, medical-equipment and electrical-equipment proxy limitations are returned with every series. Robotics and regional production are unavailable. These are not Gardner values. Board data is public domain unless otherwise indicated; cite the Board without implying endorsement.

The existing Monitor worker can refresh these series when `BTX_MARKET_REFRESH_ENABLED=true`. No new scheduler is started by the API. The existing externally scheduled worker must separately be configured and verified. `BTX_MONITOR_SCHEDULE_CONFIGURED` is a deployment declaration, not execution evidence. Health distinguishes disabled, worker-enabled/scheduler-unverified and declared scheduling. Do not claim scheduling from successful manual collection.

Refresh policy `BTX_G17_REFRESH_1`: at most one check per24hours after success; retry after one hour on failure. A20second start budget is required, with one HTTPS download capped at5MB. The shared read-only deadline bounds DNS/transport work; late results cannot publish. Database writes follow successful bounded reads and use a5second PostgreSQL lock timeout. Source changes retain immutable per-series vintages; identical replay does not create more vintages. Failure keeps prior observations and prior verification timestamps. Source SHA, native row lineage and latest refresh receipt remain inspectable.

The adapter retains up to60prior months to render36reporting months and exact-calendar YoY changes. Three-month averages require all three calendar observations. Missing cells stay null; zero-denominator growth is unavailable. Relative change is percent, not percentage points. Original and revised vintages persist; the API lists the latest24vintages and can read an exact retained ID. Retrieval and HTTP Last-Modified are not publication dates: release date currently remains unknown until separately extracted from an authoritative release record.

These additive tables can remain during a compatible code rollback. Downgrade refuses to delete source history. Use verified backup/restore for disaster recovery, not an assumed schema reversal. Orders, capacity utilization, price and regional-employment adapters are not provided by this G.17 production adapter; missing dimensions must remain explicitly unavailable until independently qualified.
