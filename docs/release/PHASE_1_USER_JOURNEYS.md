# Phase 1 Verified User Journeys

## Seller

Start on **Today**, open a current Intelligence item for a canonical Customer such as Boeing or Lockheed, inspect evidence and “Why it matters,” then open Customer 360. Review the explicit commercial SAMPLE context and missingness, inspect a validated/needs-validation relationship path or facility context, and create an internal Action. Ask Omni a follow-up: it preserves typed context and may suggest a next step, but saving the Action remains an explicit seller mutation.

## Federal Procurement

Open **Intelligence → Federal Procurement → Active Opportunities**, inspect notice, deadline, NAICS, agency, source, and Federal Opportunity Relevance factors. Explain that relevance is a draft governed consideration, not a probability. Switch to **Awarded Dollars** to distinguish historical USAspending context from forward opportunity work.

## Manager

Use the server-authorized Manager test context, open Actions, and demonstrate manager-only assignment, approval, or review where an Action requires it. Settings shows the backend-issued Manager role and permitted capabilities; a browser preference cannot elevate a Salesperson.

## Demo checks

The seller-scenarios, Actions, Omni, Federal Procurement, Relationship, Map, Settings/Communications, shared-shell, and responsive Playwright coverage verifies these journeys with deterministic fixtures.
