source URL/reference, date, event type, expected resolution, source tier, and
provenance. The canonical universe audited in Checkpoint 16 is entirely
synthetic, and no approved mapping exists from those IDs to real companies.

## Unlock criteria

1. Approved real-company identities or a replacement verified market-universe
   feed for the canonical account IDs.
2. SEC-compliant declared user agent and verified CIK evidence where applicable.
3. Approved official newsroom/IR and state-economic-development URLs, including
   a Robotics source.
4. Source-by-source human review of event type, date, entity, geography, and
   expected resolution before freezing the first 60-event release.
